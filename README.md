# Quiz Claude Code

Projeto desenvolvido como parte da **Trilha Claude Code** da **Jornada de Dados**.

### __Link da Jornada de Dados:__ https://suajornadadedados.com.br/

## Objetivo do projeto

O objetivo deste projeto foi realizar meu primeiro contato prático com o **Claude Code**, após já ter trabalhado bastante com o **ChatGPT**.

Nesta primeira etapa, o foco principal não foi o layout da aplicação, mas sim entender como trabalhar com o Claude Code em um projeto real, utilizando também um banco de dados, neste caso o **Supabase**.

O projeto foi executado localmente e o resultado foi satisfatório para este primeiro ciclo de aprendizado.

## Tecnologias e ferramentas utilizadas

* Claude Code
* Supabase
* Desenvolvimento local
* GitHub

## Próximos objetivos

Após este primeiro contato com o Claude Code, os próximos objetivos serão:

1. Desenvolver novos projetos e labs voltados para a aprendizagem e prática do uso do Claude Code.
2. Trabalhar com Claude Code na evolução de um MVP de um SaaS de Gestão Esportiva.

O MVP de Gestão Esportiva foi totalmente desenvolvido com o apoio do ChatGPT e já foi validado em situações reais.

## Contexto de evolução profissional

Esses objetivos serão desenvolvidos em paralelo com outros estudos ligados à engenharia de dados, com o objetivo de me manter atualizado em relação ao mercado de trabalho e às novas formas de desenvolvimento apoiadas por inteligência artificial.
